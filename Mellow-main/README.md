# Mellow 🍯

Mellow is a cozy and minimalist **life-tracking calendar** designed to help you document your daily journey. More than just a log, it visualizes your consistency and brings warmth to your daily routine.

### ✨ Key Features
- **Warm Aesthetic**: A soothing cream-themed UI designed for a relaxed user experience.
- **Visual Connection Lines**: Automatically connects consecutive days with the same activity (e.g., reading the same book or hitting the gym), turning your habits into a beautiful visual flow.
- **Mood Stickers**: Log your emotional state daily with a variety of cute stickers.
- **Activity Tagging**: Categorized tracking for Books, Sports, Food, Media, Games, and Travel.
- **Privacy First**: All data is stored locally in your browser's `localStorage`—your life stays yours.

### 🛠️ Tech Stack
- **React**: Core UI framework.
- **Vite**: Ultra-fast frontend build tool.
- **Lucide React**: For beautiful, consistent iconography.
- **JavaScript/ES6+**: Clean and modern logic.
